# Sistema Préstamos — V1.1 estable

Incluye navegación protegida, Ajustes JSON, notificaciones de préstamos por WhatsApp/PDF, marquee RSS, auditoría BCRA con reintentos y APIs de préstamos/cuotas/pagos.

## Configuración opcional
- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`
- `TWILIO_WHATSAPP_FROM`
- `GOOGLE_API_KEY` (si se desea integrar un redactor IA externo)

Nunca guardar credenciales en el repositorio.
